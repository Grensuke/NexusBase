# Database Design

## Execution Guidelines
1. **Relational Modeling**: Design standard relational models for MySQL.
2. **Normalization**: Strictly normalize data to 3NF by default to avoid redundant data. Denormalize only with explicit justification.
3. **Keys & Constraints**: Define explicit Primary Keys, Foreign Keys, and UNIQUE constraints.
4. **Indexes**: Plan indexes carefully based on expected access patterns.
5. **Domain Modeling**: Ensure the schema cleanly reflects the NexusBaseV2 business domains.
