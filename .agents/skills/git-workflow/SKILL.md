# Git Workflow

## Execution Guidelines
1. **Commit Quality**: Enforce meaningful, descriptive commit messages (use conventional commit style).
2. **Granularity**: Avoid giant monolithic commits. Separate unrelated changes into distinct commits.
3. **Branching**: Encourage safe branching and clean PR practices.
