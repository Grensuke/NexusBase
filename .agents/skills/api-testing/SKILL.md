# Api Testing

## Execution Guidelines
1. **Verification Scope**: Test Express endpoints for proper HTTP methods, URL routing, and status codes.
2. **Coverage**: Test success paths, validation failures, and edge cases.
3. **Security Testing**: Verify authentication walls, authorization checks, and data ownership boundaries per endpoint.
