# Accessibility

## Execution Guidelines
1. **Semantic HTML**: Prioritize native, semantic HTML elements over `div` soups.
2. **Navigation**: Ensure full keyboard navigability (tabbing, enter/space interactions).
3. **Focus States**: Implement clear, visible focus rings.
4. **Labeling**: Ensure all form inputs have accessible names and labels.
5. **Contrast**: Maintain WCAG compliant contrast ratios.
6. **ARIA**: Use ARIA attributes strictly only when native semantic HTML is insufficient.
