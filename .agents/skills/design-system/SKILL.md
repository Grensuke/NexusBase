# Design System

## Execution Guidelines
1. **Visual Consistency**: Define the strict visual tokens (colors, spacing, typography) for NexusBaseV2.
2. **Component Reuse**: Ensure all UI is built from a unified component library. Avoid one-off page-specific styles.
3. **Shadcn Integration**: Provide the rules for extending `shadcn` components to match the NexusBaseV2 brand.
4. **State Variants**: Strictly define visual states for hover, focus, disabled, and active.
