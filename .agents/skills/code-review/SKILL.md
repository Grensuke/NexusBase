# Code Review

## Execution Guidelines
1. **Architecture Check**: Verify changes respect the frontend/backend/database boundaries.
2. **Correctness & Security**: Inspect for edge cases, missing error handling, and security flaws.
3. **Complexity**: Push back on unnecessary complexity or premature abstractions.
4. **Testing**: Ensure appropriate test coverage is included with the change.
