# Documentation

## Execution Guidelines
1. **Placement**: Define where Architecture docs (e.g., `/docs/architecture`) and API/DB docs belong.
2. **Synchronization**: Enforce keeping documentation synchronized with meaningful codebase changes.
3. **Conciseness**: Avoid giant monolithic README files; use focused markdown files.
