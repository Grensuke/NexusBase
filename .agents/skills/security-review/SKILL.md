# Security Review

## Execution Guidelines
1. **Audit Scope**: Define what a NexusBaseV2 security audit should inspect (auth bypass, leakages, permission escalation).
2. **Delegation**: Delegate the actual secure coding implementation rules to `secure-coding`.
3. **Architecture**: Review the architecture for fundamental security flaws before deployment.
