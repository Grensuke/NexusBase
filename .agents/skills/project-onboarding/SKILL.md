# Project Onboarding

## Execution Guidelines
1. **Inspection**: Instruct the agent to systematically inspect repository state, rules, existing code, and dependencies BEFORE making any changes.
2. **Context Gathering**: Ensure the agent understands the exact boundaries of the codebase before engaging in active tasks.
