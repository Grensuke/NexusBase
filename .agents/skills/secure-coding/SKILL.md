# Secure Coding

## Execution Guidelines
1. **React/Express/MySQL Context**: Implement secure coding practices specific to our stack.
2. **Injection Prevention**: Sanitize all inputs to prevent SQL Injection, XSS, and command injection.
3. **Data Exposure**: Ensure APIs never over-fetch or leak sensitive internal fields (e.g. password hashes).
4. **OWASP**: Adhere to standard OWASP Top 10 mitigations during code generation.
