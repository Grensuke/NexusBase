# Unit Integration Testing

## Execution Guidelines
1. **Distinction**: Clearly define what constitutes a Unit Test (isolated, fast) vs an Integration Test (database/service boundaries).
2. **Focus**: Prioritize unit tests for business-critical logic (Services/Utils).
3. **Determinism**: Ensure tests are deterministic and do not depend on external live state.
