# Test Strategy

## Execution Guidelines
1. **Balancing**: Decide the testing pyramid for the current feature: what requires unit tests vs integration vs E2E.
2. **Risk Assessment**: Identify which critical business flows require regression protection.
3. **Coverage vs Value**: Optimize for testing value over arbitrary line-coverage metrics.
